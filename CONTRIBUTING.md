# Contribution workflow policy

This companion may automatically collect redacted local diagnostic evidence and prepare a draft. Publication is never automatic.

A contribution to `Blackwellboy/model-serving-minefield` requires an explicit affirmative user reply for the pending draft. Before submission, re-read the current upstream contribution rules and PR template, inspect the complete diff for public-safety issues, run the upstream integrity checks, and submit only the minimum contribution authorized by the user.

A review request is not publication consent. A denial or cancellation ends the publication flow. Raw session logs remain local unless the user separately and explicitly chooses to publish specific sanitized evidence.
